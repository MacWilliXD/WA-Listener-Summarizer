# WA-Listener-Summarizer

![Logo](https://img.shields.io/badge/Android-8%2B-brightgreen?style=flat-square) ![Kotlin](https://img.shields.io/badge/Kotlin-Android-blue?style=flat-square) ![Room](https://img.shields.io/badge/Room-Database-orange?style=flat-square)

**WA-Listener-Summarizer** es una aplicación Android que escucha las notificaciones de WhatsApp y genera resúmenes diarios de tus chats, todo guardado localmente en tu dispositivo. Ideal para analizar, consultar y limpiar tu historial de mensajes de forma privada y sencilla.

---

## ✨ Características

- Escucha y almacena notificaciones de WhatsApp (mensajes individuales y grupos)
- Lista de chats con contador de mensajes no leídos
- Vista de mensajes por chat
- Resúmenes diarios automáticos por chat
- Filtro de fechas para ver resúmenes de un rango específico
- Elimina chats, mensajes y resúmenes fácilmente
- Todo se guarda localmente (privacidad total)

## 🚀 Instalación y uso

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/tuusuario/WA-Listener-Summarizer.git
   ```
2. **Abre el proyecto en Android Studio**
3. **Compila y ejecuta en un dispositivo Android 8.0+**
4. **Otorga el permiso de acceso a notificaciones** cuando la app lo solicite
5. ¡Listo! Tus chats y resúmenes aparecerán automáticamente

---

## ⚙️ Tecnologías y dependencias

- **Kotlin**
- **Room Database** (persistencia local)
- **ViewModel & LiveData** (arquitectura MVVM)
- **Material Design**
- **RecyclerView, ConstraintLayout, CoordinatorLayout**

---

## 🛡️ Privacidad

Esta app **no envía datos a ningún servidor**. Todo se almacena localmente en tu teléfono. El acceso a notificaciones es solo para leer mensajes de WhatsApp y generar los resúmenes.
